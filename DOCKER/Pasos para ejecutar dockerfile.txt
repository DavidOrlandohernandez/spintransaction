2.- Comprobacion de la imagen : docker images / app:latest   432408856830        629MB          226MB    U
3.- Crear el contenedor  : docker run -p 8085:8085 -e SPRING_PROFILES_ACTIVE=prod app
Nota: Uso de perfiles prod, test, dev
